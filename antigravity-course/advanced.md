## ເປົ້າໝາຍການຮຽນ

ຮຽນຈົບແລ້ວ ຜູ້ຮຽນສາມາດ:

1. ສອນ Agent ໃຫ້ເຮັດວຽກຕາມມາດຕະຖານຂອງອົງກອນ ດ້ວຍ **Rules** ແລະ **Skills**
2. ສະກັດຂໍ້ມູນຈາກເອກະສານເຄລມ (PDF ແລະ ຮູບຖ່າຍ) ເຂົ້າຕາຕະລາງ ແລະ ກວດຄວາມຄົບຖ້ວນ
3. ສ້າງເຄື່ອງມືຄິດໄລ່ຄ່າສິນໄໝທົດແທນ ທີ່ອະທິບາຍວິທີຄິດໄດ້ທຸກຂັ້ນ
4. ກວດຫາເຄລມທີ່ມີສັນຍານຄວາມສ່ຽງ (Red Flags) ກ່ອນອະນຸມັດ
5. ສ້າງ Dashboard ຕິດຕາມເຄລມ ແລະ ຕັ້ງວຽກໃຫ້ແລ່ນອັດຕະໂນມັດຕາມເວລາ
6. ໃຊ້ Agent Manager ໃຫ້ຫຼາຍ Agent ເຮັດວຽກພ້ອມກັນ ແລະ ຄຸມຄຸນນະພາບຜົນງານ

**ລະບົບຕົ້ນແບບ 5 ຢ່າງ ທີ່ສ້າງເອງ (ເອົາໄປປັບໃຊ້ໃນວຽກໄດ້ທັນທີ)**
1. ລາຍງານເຄລມປະຈຳອາທິດ ກົດດຽວ (ຫຼື ແລ່ນເອງຕາມເວລາ)
2. ລະບົບກວດເອກະສານເຄລມ + ຮ່າງຈົດໝາຍຂໍເອກະສານເພີ່ມ
3. Claim Calculator ທີ່ອະທິບາຍວິທີຄິດທຸກຂັ້ນ
4. Red Flag Checker ຊອກເຄລມທີ່ຄວນກວດເພີ່ມ
5. Dashboard ຕິດຕາມເຄລມ ແລະ SLA

**ໂປຣເຈັກຈາກວຽກຕົວຈິງ**
- Final Project 1 ຊິ້ນ ທີ່ແກ້ບັນຫາໃນວຽກຂອງທ່ານເອງ ພ້ອມແຜນນຳໄປໃຊ້

**ເອກະສານ ແລະ ການຊ່ວຍເຫຼືອ**
- ຊຸດ Rules ແລະ Skills ແມ່ແບບ ສຳລັບທີມເຄລມ
- ຊຸດຄຳສັ່ງ (Prompt) ຂັ້ນສູງ 50+ ແບບ
- ຄູ່ມືການຮຽນພາສາລາວ (PDF)
- ໃບຢັ້ງຢືນ Antigravity Advanced
- ກຸ່ມຖາມ-ຕອບຫຼັງຮຽນ 60 ມື້
- ປຶກສາ 1:1 ອອນລາຍ 30 ນາທີ ຫຼັງຮຽນຈົບ 1 ຄັ້ງ

**ເງື່ອນໄຂໄດ້ຮັບໃບຢັ້ງຢືນ:** ເຂົ້າຮຽນຢ່າງໜ້ອຍ 3 ໃນ 4 ມື້ ແລະ ນຳສະເໜີ Final Project.
