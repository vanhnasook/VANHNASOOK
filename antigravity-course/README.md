# ຫຼັກສູດ Antigravity ສຳລັບວຽກຫ້ອງການ ແລະ ວຽກເຄລມປະກັນໄພ

ຫຼັກສູດອົບຮົມການໃຊ້ **Google Antigravity** (ເຄື່ອງມື AI Agent ຂອງ Google) ສຳລັບພະນັກງານຫ້ອງການ ແລະ ພະນັກງານເຄລມປະກັນໄພ. ຮຽນ **ວັນເສົາ-ອາທິດ ມື້ລະ 2 ຊົ່ວໂມງ**. ບໍ່ຕ້ອງຂຽນໂປຣແກຣມເປັນ.

| | Basic | Advanced |
|---|---|---|
| ຊົ່ວໂມງຮຽນ | 4 ຊົ່ວໂມງ | 8 ຊົ່ວໂມງ |
| ຕາຕະລາງ | 1 ເສົາ-ອາທິດ (2 ມື້) | 2 ເສົາ-ອາທິດ (4 ມື້) |
| ລາຄາ | **1,500,000 ກີບ** | **2,500,000 ກີບ** |
| ເປົ້າໝາຍ | ເລີ່ມໃຊ້ AI Agent ກັບວຽກ Excel, ທະບຽນເຄລມ ແລະ ຈົດໝາຍເຄລມ | ສ້າງລະບົບອັດຕະໂນມັດ: ກວດເອກະສານ, ຄິດໄລ່ເຄລມ, Red Flags, Dashboard |
| ເໝາະກັບ | ຜູ້ທີ່ຍັງບໍ່ເຄີຍໃຊ້ AI Agent | ຜູ້ຜ່ານ Basic ຫຼື ເຄີຍໃຊ້ AI Agent |
